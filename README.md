# Pushly — PushUp Wars

Native iOS (Swift/SwiftUI) + Android (Kotlin/Compose) app with a Supabase backend.
Alarm that rings until the camera sees your push-ups, live 1v1 push-up battles, leaderboards, clans and Clan Wars.
